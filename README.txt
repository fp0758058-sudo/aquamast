AQUAMAST — DEMO WEBSITE

Files:
- index.html — static website entry point.

Deploy:
1. Open Cloudflare Dashboard > Workers & Pages.
2. Select the existing Worker "aquamast".
3. Open its deployment/upload flow for static assets.
4. Upload the contents of this folder (or the ZIP if the interface accepts ZIP uploads).
5. Deploy, then test https://aquamast.cryptousdt.workers.dev

Important:
This is a demo-only website. The calculator uses a fictional fixed rate of 88 RUB per USD.
It does not provide currency exchange, transfers, payment processing, or storage of financial data.
Do not use it to accept customer funds or represent the demo rate as a live market rate.
